# Retail Sales & Customer Analytics with Revenue Prediction

## Project Overview
This project analyzes retail sales data using Python and Power BI to generate business insights and predict revenue using a Linear Regression model.

## Objectives
- Analyze customer purchasing behavior
- Identify top-performing product categories
- Study revenue trends
- Predict total revenue using regression
- Build an interactive Power BI dashboard

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Power BI

## Machine Learning Model
- Linear Regression

## Key Insights
- Quantity sold is the strongest factor affecting revenue
- Product pricing positively impacts sales performance
- The model achieved an R² Score of approximately 0.85
